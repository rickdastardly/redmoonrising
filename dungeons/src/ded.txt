# DED complexes, researched from public guides (EVE University wiki) for the
# sites as they stood after Red Moon Rising. Rooms, groups and bosses follow
# the guides; gate distances are estimates where the guides give none.
#
# = id | name | faction | rating
# > room name | open|locked | gate distance in km (0: last room)
#   count names/separated/by/slash @ class        a group in the room's arrival wave
#   * count name @ class                           a boss (overseer)
#   + count names @ class                          starts a wave that comes once the room is clear
# Classes: f frigate, d destroyer, c cruiser, bc battlecruiser, bs battleship.
# A name the game does not have becomes a deadspace ship of that class.
